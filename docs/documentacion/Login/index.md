# 🔐 Módulo de Inicio de Sesión (Login)

El módulo de **Inicio de Sesión** de **PokeSystem** gestiona la autenticació y la verificación de credenciales de los usuarios.

---

## 🛠️ Características Principales

- **Autenticación Segura:** Hash de contraseñas con algoritmos estándar de Laravel (Bcrypt/Argon2).
- **Protección contra Fuerza Bruta:** Limitación de intentos (*Rate Limiting*) en endpoints de login.
